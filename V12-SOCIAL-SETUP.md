# Memory Card v12 — профили и друзья

## Один раз: обновить Apps Script владельца

1. Открой Google Sheet, который сейчас используется Memory Card.
2. Extensions / Расширения → Apps Script.
3. Полностью замени текущий `Code.gs` содержимым `Code.gs` из этого репозитория.
4. Сохрани проект.
5. Deploy / Развернуть → Manage deployments / Управление развертываниями.
6. Открой существующий Web App → Edit → New version → Deploy.
7. Старый `/exec` URL и существующий `SYNC_SECRET` менять не нужно.

При первом подключении v12 существующие `Games` и `Settings` автоматически становятся профилем владельца. Создаются служебные листы `Profiles`, `ProfileDevices`, `UserSettings`, `Friends`. Игры не нужно переносить вручную.

## Профиль владельца

После обновления Apps Script открой Memory Card → Настройки. Приложение автоматически присвоит ID вида `MC-AB12-CD34`. Имя можно изменить там же.

Старые устройства владельца, на которых уже сохранён `SYNC_SECRET`, автоматически подключатся к тому же профилю и получат отдельный приватный device token.

## Как дать доступ другу

Другу нужны:

- ссылка на Memory Card / GitHub Pages;
- тот же Apps Script `/exec` endpoint.

`SYNC_SECRET` владельца другу передавать не нужно.

Друг открывает Настройки, вставляет endpoint, вводит своё имя и сохраняет настройки. Сервер создаёт отдельный профиль, отдельную библиотеку и выдаёт отдельный Memory Card ID.

Далее один пользователь открывает раздел **Друзья**, вводит точный ID второго и отправляет приглашение. Профили становятся доступны друг другу только после принятия приглашения.

## Что видно друзьям

После подтверждения дружбы доступны read-only:

- имя и Memory Card ID;
- список используемых приставок;
- общая статистика;
- текущие игры;
- завершённые игры и оценки.

Удалённые записи и личные заметки сервер друзьям не отдаёт.

## Экспорт / импорт

Экспорт v12 содержит профиль, игровые настройки, выбранные приставки, ротации и игры. Публичный ID сохраняется в JSON как информация, но при импорте не заменяет серверную личность текущего пользователя.

Никогда не экспортируются:

- приватный `authToken`;
- `SYNC_SECRET`;
- Apps Script endpoint как credential;
- реальные серверные связи дружбы.

Это сделано специально, чтобы импорт чужого JSON не позволял захватить чужой профиль.
