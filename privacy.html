Конфиденциальность и данные

Предрелизная информация · обновлено 7 ноября 2026 года

Статус: это предварительное описание обработки данных для тестовой версии Memory Card. До публикации в Google Play необходимо уточнить официальный канал поддержки, сроки хранения резервных копий и окончательные сведения Data safety.

Какие данные используются

При регистрации Memory Card обрабатывает адрес электронной почты, данные входа и имя профиля. Пароль проверяется сервисом Supabase Auth; приложение не хранит пароль в собственной таблице игр. Supabase может хранить данные аутентификации и технические сведения о сеансах.

Игровая библиотека может включать названия и платформы игр, статусы прохождения, оценки, жанры, даты, личные комментарии, коллекции, настройки и информацию о друзьях. Это данные, которые ты добавляешь в приложение самостоятельно.

Где хранятся данные

Локальные записи, черновики и резервные снимки хранятся в IndexedDB браузера на устройстве. Сессия входа Supabase может храниться локально, чтобы не требовать пароль при каждом открытии.

Облачная синхронизация использует Supabase Auth и PostgreSQL. В текущем релизе библиотека привязана к аккаунту, а изменения игр проверяются сервером. Для пользователя, который разрешил доступ в друзья, могут отображаться его имя, выбранные платформы, часть игровой библиотеки и статистики. Личные комментарии и Backlog не входят в выдачу профиля друга по текущей серверной функции.

Внешние сервисы

Memory Card использует Cloudflare Turnstile для защиты входа от автоматизированных запросов и загружает JavaScript-библиотеку Supabase через jsDelivr. Поиск игровых данных и обложек может обращаться к Wikidata, Wikipedia, GitHub/Libretro, GameTDB и другим указанным в коде источникам изображений. Эти сервисы получают обычные технические сведения о веб-запросах, в том числе IP-адрес; поисковый запрос может содержать название искомой игры.

При экспорте карточки игры в PNG изображение формируется на устройстве; выбранная обложка может быть загружена по внешнему URL. Memory Card не должна отправлять личные отзывы внешнему источнику обложки.

Как управлять данными

В настройках Memory Card можно экспортировать свою игровую библиотеку в JSON. Пользователь также может самостоятельно удалить сохранённые данные сайта из браузера; это не удалит облачный аккаунт.

Запросить удаление аккаунта и связанных данных можно через отдельную веб-страницу даже после удаления приложения. Запрос регистрируется после входа и обрабатывается отдельно; он сам по себе не запускает мгновенное удаление. При подтверждённом удалении учётной записи соответствующие таблицы активной облачной базы удаляются каскадно, но локальные экспортированные файлы и резервные копии провайдера могут требовать отдельных сроков очистки. Эти сроки уточняются перед публичным релизом.

Безопасность и ограничения

Передача данных в Supabase ведётся по HTTPS. На уровне базы действуют политики доступа RLS. Однако браузерные данные не следует считать зашифрованным персональным сейфом: человек с доступом к устройству или профилю браузера может получить доступ к локальным данным. Вход в другой аккаунт не означает физического удаления копий предыдущего аккаунта.

Связаться с разработчиком

Пока частный адрес для обращений по конфиденциальности не опубликован. Для обычных технических вопросов доступен публичный трекер проблем Memory Card. Не публикуй там пароль, email, токен или личные игровые заметки. Перед публичной публикацией будет указан безопасный приватный канал связи.
