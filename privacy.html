Конфиденциальность Memory Card

Предварительная версия — 9 ноября 2026 года. Это публичное техническое уведомление об имеющихся функциях приложения, а не окончательно утверждённая политика для магазина Google Play. Перед открытой регистрацией должны быть добавлены подтверждённый контакт оператора и сроки хранения резервных копий.

Какие сведения сохраняются

При регистрации Supabase Auth обрабатывает email и сведения об аутентификации. В базе Memory Card сохраняются отображаемое имя, идентификатор игрока, настройки, игровые записи (названия, платформы, статусы, оценки, заметки, даты), коллекции, дружеские связи и запросы на удаление.

Для защиты от спама хранятся события приглашений, списки блокировок и отправленные жалобы (причина, необязательный текст, отправитель, адресат и дата). Жалобы доступны только уполномоченному оператору базы, а не другим пользователям приложения.

На устройстве браузер хранит игровой журнал, локальные резервные копии, служебные снимки синхронизации и настройки в IndexedDB и localStorage. Экспортированные пользователем JSON-файлы остаются у него.

Сервисы и сетевые подключения

Авторизация и облачная база работают через Supabase; действующий проект размещён в регионе Seoul (ap-northeast-2). Сам веб-сайт размещён на GitHub Pages. Для проверки входа используется Cloudflare Turnstile; веб-библиотека Supabase загружается с jsDelivr.

Каталоги названий игр могут обращаться к внешним источникам метаданных. Внешние изображения обложек по умолчанию выключены на каждом устройстве. Если их включить в Настройки → Каталоги, браузер может обращаться к GameTDB, Wikimedia, GitHub-серверам и другим поставщикам изображений. Эти сервисы могут видеть IP-адрес и технические параметры запроса. Memory Card не гарантирует наличие прав на каждую обложку.

Видимость и передача

Список игр и часть статистики могут показываться подтверждённым друзьям в приложении. Личные заметки и Backlog не предназначены для просмотра друзьями. Жалобы на пользователей не публикуются. Memory Card не заявляет о продаже пользовательских игровых данных; перед релизом будет завершена независимая проверка всех интеграций и потоков данных.

Экспорт и удаление

Данные игровой библиотеки можно экспортировать в JSON внутри приложения. Запрос на удаление аккаунта принимается в приложении и на отдельной веб-странице. Отправка запроса сама по себе ещё не удаляет аккаунт. Подтверждённое удаление через защищённую серверную функцию требует повторной проверки пароля и удаляет учётную запись вместе со связанными таблицами через каскадные связи.

Открыть страницу удаления аккаунта

Ручные запросы, которые пользователь не завершил самостоятельно, пока требуют обработки оператором. Данные браузера на других устройствах и экспортированные вручную файлы не могут быть удалены удалённо. Конкретные сроки хранения резервных копий Supabase и операционные сроки обработки запросов ещё не подтверждены; эти вопросы блокируют публичный запуск.

Вопросы и обращения

Проверенный приватный контакт поддержки разработчика пока не опубликован. Перед открытой регистрацией он должен быть указан здесь и в Google Play. Не публикуйте пароли, письма, персональные заметки и чувствительные сведения в открытых GitHub Issues.
