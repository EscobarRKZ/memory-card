# Changelog — Memory Card

Здесь фиксируются заметные пользовательские изменения Memory Card. Мелкие технические коммиты, обновления кэша и промежуточные правки объединены в релизные вехи.

## v0.12 — Profiles & Friends

**13 сентября 2026**

Крупное обновление, превращающее Memory Card из персонального трекера в небольшую закрытую игровую сеть.

### Новое

- Добавлены персональные профили с уникальным Memory Card ID формата `MC-XXXX-XXXX`.
- Добавлено редактируемое отображаемое имя профиля.
- Добавлен раздел **«Друзья»**.
- Поиск пользователей работает только по точному Memory Card ID.
- Добавлены заявки в друзья: отправка, принятие и отклонение.
- Профили других пользователей доступны только после подтверждения дружбы.
- Добавлен read-only профиль друга со статистикой, текущими играми, завершёнными играми, оценками и используемыми консолями.
- Личные заметки и удалённые записи друзьям не передаются.
- Добавлена возможность удалить пользователя из друзей.

### Консоли и ротации

- Добавлен выбор консолей, которыми пользователь реально владеет или пользуется.
- Портативная и стационарная ротации теперь включаются независимо друг от друга.
- Nintendo Switch относится к стационарной ротации.
- Ротации больше не заполняются автоматически всеми существующими платформами.
- В редакторе ротации можно добавлять, удалять и менять порядок только нужных пользователю систем.
- Добавлены небольшие визуальные иконки устройств.

Добавлены платформы:

- PlayStation, PlayStation 2, PlayStation 4, PlayStation 5;
- Xbox, Xbox 360, Xbox One, Xbox Series;
- Nintendo Wii, GameCube, Nintendo 64, SNES, NES;
- Sega Dreamcast, Mega Drive / Genesis;
- сохранены PSP, PS Vita, DS / DSi, 3DS, GBA, PS3, Wii U и Nintendo Switch.

### Синхронизация и сервер

- Google Apps Script backend переведён на многопользовательскую модель.
- Добавлены отдельные профили, device-токены, настройки пользователей и связи дружбы.
- Существующая библиотека автоматически мигрирует в профиль владельца при первом подключении v0.12.
- Данные разных пользователей хранятся раздельно.
- Доступ к профилю друга проверяется на сервере, а не только интерфейсом.
- Для существующего владельца сохранена совместимость с `SYNC_SECRET`.
- Восстановлен устойчивый Apps Script iframe bridge с передачей сообщений через `parent` и `top`.

### Экспорт и импорт

- Экспорт теперь содержит игры, публичные данные профиля, выбранные консоли и настройки ротаций.
- `authToken`, `SYNC_SECRET` и Apps Script endpoint не экспортируются как credentials.
- Импорт чужого JSON не может заменить серверную личность текущего пользователя.

## v0.11 — UX, Sync & Covers

**12 сентября 2026**

Большой стабилизационный релиз: мобильный интерфейс, синхронизация между устройствами, производительность библиотеки и серьёзная переработка загрузки обложек.

### Интерфейс

- Исправлены переполнения и ширина интерфейса на мобильных устройствах.
- Нижняя навигация закреплена и адаптирована под мобильный экран.
- Убрана неудобная горизонтальная прокрутка ротаций.
- Добавлены более наглядные кнопки платформ с иконками.
- Добавлена сортировка игровой библиотеки.
- Поиск библиотеки переведён на поиск именно по названию игры.
- Исправлено мерцание сортировки и фильтров при перерисовке интерфейса.
- Черновик формы игры теперь сохраняется при фоновых обновлениях интерфейса.

### Производительность

- Исправлен цикл перерисовки, из-за которого раздел игр мог зависать.
- Поиск и фильтрация переведены с лишних observers на событийную модель.
- Убраны лишние observers у кнопок платформ и сортировки.
- Загрузка обложек Nintendo Switch вынесена из критического пути интерфейса.
- Стартовая синхронизация сделана неблокирующей.

### Синхронизация

- Улучшена автоматическая синхронизация между устройствами при открытии и возвращении в приложение.
- Убрана дублирующая логика autosync, вызывавшая лишние запросы.
- Сохранён local-first подход: локальные данные остаются основой приложения, а Google Sheets используется для синхронизации и резервирования.

### Обложки и каталог

- Приведён к единому виду размер обложек без агрессивного кропа box-art.
- Добавлены дополнительные источники и fallback-механизмы для Nintendo Switch.
- Существенно улучшено восстановление отсутствующих обложек PS3.
- Добавлены GameTDB и Wikipedia fallback для PS3.
- Улучшены повторы запросов после неудачной загрузки обложки.
- Неудачные ответы больше не сохраняются как постоянный кэшированный результат.
- Добавлена база обложек по title ID.
- Улучшено восстановление обложек PS Vita через VitaDB и HexFlow.
- Массовое обновление обложек стало repository-backed и автоматически скрывается после завершения.
- Обновление каталога получило более устойчивые fallback-механизмы.

## v0.10 — Core Memory Card

Базовая версия приложения, на которой построены последующие релизы.

### Основные возможности

- Персональная игровая библиотека со статусами прохождения.
- Список игр «Сейчас играю» и завершённых игр.
- Оценки, заметки и базовая статистика.
- Таймлайн игровой истории.
- Раздельные ротации портативных и стационарных систем.
- Локальное хранение данных в браузере.
- Синхронизация с Google Sheets через Apps Script.
- Импорт и экспорт данных.
- Установка как PWA.
- Автоматическая работа с каталогами игр и обложками.

## Версионирование

Начиная с v0.12 changelog рекомендуется обновлять при каждом заметном пользовательском релизе. Мелкие исправления внутри одной версии можно группировать в секции `Fixed` / `Changed`, не создавая отдельную версию для каждого технического коммита.
