# Changelog — Memory Card

## PWA build v86 — безопасные права БД и проверки релизной сборки

**7 ноября 2026**

- В рабочем Supabase применена миграция `20261107173126`: у клиентских ролей `anon` и `authenticated` отозваны `TRUNCATE`, `TRIGGER`, `REFERENCES` на таблицы `public`. Проверены отсутствие этих прав, сохранность 110 игр и двух аккаунтов.
- Прямые `INSERT/UPDATE/DELETE` на `games` пока сохранены для совместимости со старыми PWA; финальное отключение ждёт проверки работы v82+ на реальных устройствах.
- Версия браузерного `@supabase/supabase-js` закреплена на `2.95.0` в приложении, странице удаления и тестовой странице. Это не заменяет SRI/полный аудит зависимостей.
- CI теперь проверяет PWA build/cache, существование файлов в offline precache, внешнюю страницу удаления, локальные скрипты и закреплённую версию SDK; включён тест service worker.
- Добавлен документ со списком блокирующих требований Google Play и предварительным Data safety inventory. **Тесты не подтверждают доступность GitHub Pages, работу на реальном телефоне и удаление настоящего тестового аккаунта.**


## PWA build v85 — удаление аккаунта с повторным подтверждением

**7 ноября 2026**

- Развёрнут Supabase Edge Function `delete-own-account`, доступный только по действующему JWT и после уже зарегистрированной собственной заявки.
- Для окончательного удаления на внешней странице требуется текущий пароль, отдельная проверка Turnstile и точная фраза «УДАЛИТЬ НАВСЕГДА». Пользователь ещё раз подтверждает необратимость.
- Сервер перепроверяет пароль и владельца через Supabase Auth; только серверный привилегированный клиент может удалить запись Auth. Облачные игровые данные удаляются через каскадные связи.
- После подтверждённого ответа сайт пытается убрать локальный снимок удалённого аккаунта из IndexedDB, сохраняя другие аккаунты и гостевой архив.
- Новые автоматические тесты проверяют отсутствие прав у неавторизованных запросов, неверный пароль, отсутствие заявки, отказ при наличии Storage buckets, отсутствие подмены UID и очистку локальных записей.
- **Не готово для публичного Google Play:** реальный тест удаления на специальном тестовом аккаунте, подтверждение опубликованной страницы, ручная обработка незавершённых заявок и утверждённая политика конфиденциальности.

## PWA build v83 — отдельные локальные библиотеки (релизный этап)

**7 ноября 2026**

- Каждому Supabase-аккаунту соответствует собственный локальный IndexedDB-снимок. Переход между аккаунтами переключает снимки атомарно, а не объединяет их.
- После выхода активный экран освобождается от данных предыдущего аккаунта; при следующем входе данные восстанавливаются из его собственной локальной копии.
- Гостевая/старосистемная библиотека архивируется отдельно и может быть импортирована вручную. Совпадающие ID не перезаписываются; гостевой архив сохраняется.
- Локальные резервные копии разделены по аккаунтам; известные старые копии сохраняются при первом переходе.
- Запись из устаревшей вкладки блокируется, если в IndexedDB уже открыт другой аккаунт (защита нового клиента, не старого v82).
- Тесты переключения A → выход → B → A, гостевого импорта, отказа IndexedDB и изоляции старой вкладки добавлены в CI.
- Серверных изменений в v83 нет. Прямые права записи старых PWA пока не отозваны. Реальные Android/двухаккаунтные тесты и удаление аккаунта всё ещё остаются условиями выпуска в Google Play.

Заметка о релизе: v82 — первый этап серверной защиты синхронизации; это ещё не готовый релиз Google Play.

## PWA build v82 — серверная проверка конфликтов (первая фаза)

**7 ноября 2026**

- Синхронизация новых и изменённых игр переведена на защищённый Supabase RPC. Владелец записи определяется по авторизации, а не по параметру из браузера.
- Существующая игра обновляется только если версия в облаке совпадает с той, которую видел клиент. При конфликте остаются обе версии и выбор в Настройки → Аккаунт.
- Сервер сам назначает время новой версии. Новые игры отправляются пакетами не более 100; неуспешный RPC-пакет откатывается целиком.
- В Supabase установлена миграция 20261107105332. Тестовая транзакция на рабочем сервере подтвердила отклонение устаревшей версии и отсутствие оставленных тестовых строк.
- **Этап не завершён полностью:** прямые права записи старых PWA ещё открыты. Они будут отозваны только после проверки v82 на телефоне, чтобы не оборвать синхронизацию старым установкам. Публичная регистрация пока не готова.

Здесь фиксируются заметные пользовательские релизы. Мелкие технические коммиты и cache bumps объединяются в продуктовые версии.

## v0.17.5 — Tactile layer

**7 ноября 2026**

- Новый отдельный слой `tactile-v78.css/js`: существующие стили и логика не заменялись, слой подключается последним.
- **Вибрация** на Android: тик на навигацию и карточки, паттерны на сохранение («Записано на карту»), предупреждение на опасные действия, порог при свайпе шторки. Переключатель **«Вибрация»** в Настройки → Оформление хранится только на устройстве. На iPhone браузер не даёт Vibration API, переключатель там неактивен.
- **Нажатия**: карточки, кнопки и пункты навигации слегка «проминаются» и пружинят обратно.
- **Звёзды рейтинга**: «поп» и свечение выбранной звезды, выбор рейтинга движением пальца по звёздам.
- **Шторки и модалки**: свайп вниз с «резинкой» и затуханием подложки (шторка «Ещё», форма и карточки на телефоне, окно шаринга), мягкое появление окон.
- **Нижняя навигация**: стеклянный фон и «таблетка», которая переезжает к активному пункту.
- **Глубина и обложки**: единая шкала теней, глянец и кромка на обложках, skeleton при загрузке и мягкое проявление картинки, пришедшей по сети.
- **Тост сохранения**: появление с пружиной и двойное мигание «светодиода» карты.
- **Переходы между разделами** через View Transitions API там, где он есть; параллакс фона hero.
- Всё уважает `prefers-reduced-motion` и настройку «Меньше анимаций».
- Тест: `tests/test_v78.py` (40 проверок в настоящем Chromium, внешняя сеть заблокирована).

## v0.17.3 — Cover Picker

**13 сентября 2026**

- Кнопка **«Обновить обложку»** больше не принимает повторно тот же URL как успешный результат.
- Текущая обложка исключается из списка кандидатов.
- Добавлен визуальный выбор альтернативных обложек с превью.
- Сначала ищутся строгие совпадения названия в Libretro Named_Boxarts, затем точный локальный каталог, общий resolver и варианты Wikipedia.
- Нормализация понимает варианты римских и арабских цифр (`II` ↔ `2`, `III` ↔ `3`) и региональные суффиксы.
- После ручного выбора корректная обложка записывается и в соответствующую запись локального каталога, чтобы ошибочный вариант не возвращался снова.
- Если автоматические источники не нашли нужную картинку, можно вставить прямой URL вручную.
- Обычный автоматический поиск будущих обложек теперь также предпочитает строгое Libretro-совпадение перед fuzzy resolver.
- Service Worker cache: `memory-card-v41-cover-picker`.
- Apps Script остаётся **version 16**.

## v0.17 — Backlog, Rotation & Visual polish

**13 сентября 2026**

### Backlog

- Форма Backlog теперь использует тот же локальный игровой каталог, что и основная библиотека.
- При вводе названия появляются подсказки каталога; при выборе автоматически заполняются название, год, жанр и франшиза, если они известны.
- При добавлении используется уже найденная catalog cover, затем обычный cover resolver как fallback.

### Главная и ротация

- Исправлено переключение текущей приставки из настроек: выбранная система сразу сохраняется и корректно отражается на главной и в карточках ротации.
- Currently Playing hero теперь учитывает ротацию.
- Если обе ротации отключены, при каждом открытии/обновлении главной случайно выбирается одна из всех текущих playing-игр.
- Если ротация включена, hero выбирает случайную playing-игру только среди текущих платформ включённых ротаций.
- Режимы **Классическая / Баланс / Случайная** заменены с select на крупные кнопки с короткими пояснениями.

### Обложки

- На detail-page игры добавлена кнопка **«Обновить обложку»**.
- Ручное обновление сначала пытается найти строгое совпадение в Libretro Named_Boxarts, включая нормализацию римских цифр (`II` ↔ `2`), затем использует точный каталог и обычный resolver.
- Это уменьшает риск ложных совпадений вроде Assassin's Creed II → Assassin's Creed III.

### Коллекции

- Добавление и удаление игр из коллекций переведено на immutable update настроек.
- Исправлены случаи, когда добавление визуально срабатывало, но затем терялось после re-render/sync.

### Визуал

- Исправлен плохой контраст тёмных плашек в светлой теме на странице игры и в настройках.
- Акцентные темы переработаны в визуальные карточки с названиями.
- Добавлено ещё 12 консольных стилей: **PS1 Smoke, PSP XMB, PS3 Wave, Switch Neon, GameCube Indigo, Wii Ice, Nintendo 64, SNES Lavender, Mega Drive, Xbox 360 Blades, DSi White, 3DS Red**.
- Всего теперь 24 visual styles; первые 8 показываются сразу, остальные скрыты под **«Показать все стили»**.
- Со страницы достижений убрана лишняя строка про playtime.

### Техническое

- Добавлены `product-v17.js` и `product-v17.css` как отдельный compatibility/polish layer поверх v0.16.
- Service Worker cache: `memory-card-v35-product-v17`.
- Apps Script остаётся **version 16**; повторный deploy для v0.17 не требуется.
