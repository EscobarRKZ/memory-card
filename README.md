# Memory Card v0.14

**Memory Card** — local-first PWA для личной игровой библиотеки, истории прохождений, ротации консолей и небольшой закрытой социальной сети для друзей.

Приложение работает в браузере и устанавливается как PWA на телефоне и компьютере. Основные данные хранятся локально, а Google Sheets + Apps Script используются для синхронизации между устройствами и профилями.

## Что умеет Memory Card

- библиотека игр со статусами **«Играю»**, **«Пройдено»**, backlog и dropped;
- оценки, заметки, даты, перепрохождения и история;
- отдельные ротации портативных и стационарных устройств;
- выбор собственных приставок и скрытие неиспользуемых систем;
- несколько видов библиотеки: **4 / 6 / 8 карточек в ряд** и подробный горизонтальный список;
- статистика по выбранным платформам и всем франшизам;
- каталоги игр и автоматический поиск box art;
- профили с уникальным Memory Card ID;
- заявки в друзья и read-only профили друзей;
- Русский / English;
- Google Sheets sync, локальные snapshots, JSON export/import.

# Ротация устройств

Memory Card позволяет вести две независимые очереди.

### Портативная

`DSi → PS Vita → 3DS → PSP → GBA → ...`

### Стационарная

`PS3 → Wii U → Nintendo Switch → ...`

Порядок полностью настраивается. Любую из ротаций можно отключить. После завершения активной игры Memory Card может сохранить оценку и автоматически переключить текущую систему на следующую.

# Профили и друзья

После подключения к Apps Script пользователь получает ID вида:

`MC-AB12-CD34`

Чтобы добавить друга:

1. Открой **«Друзья»**.
2. Введи точный Memory Card ID.
3. Отправь заявку.
4. Второй пользователь принимает её.
5. После подтверждения становятся доступны read-only игровые профили.

Личные заметки не передаются другу. Если дружба удалена, сервер сразу закрывает доступ к профилям в обе стороны.

# Каталоги и обложки

Обычная кнопка обновления каталога работает только с платформами из **«Мои приставки»**. Рядом есть полное обновление всех поддерживаемых платформ.

Источники каталогов включают platform-specific SQL-базы и GameTDB. Для PS5 и Xbox Series отдельного источника каталога пока нет.

Для обложек используются:

- Libretro Thumbnails / `Named_Boxarts`;
- GameTDB;
- title-ID базы;
- Wikipedia как строгий fallback;
- VitaDB / HexFlow для PS Vita;
- platform-specific helpers.

Если достоверную box art найти не удаётся, Memory Card предпочитает fallback-карточку случайной неправильной картинке.

# Google Sheets + Apps Script

Google Sheets используется как облачная база и точка синхронизации.

## Первичная настройка владельца

1. Создай Google Sheet для Memory Card.
2. **Расширения → Apps Script**.
3. Замени содержимое `Code.gs` файлом `Code.gs` из корня репозитория.
4. **Project Settings → Script Properties**.
5. Создай `SYNC_SECRET` со случайным длинным значением.
6. **Deploy → New deployment → Web app**.
7. **Execute as:** Me.
8. **Who has access:** Anyone.
9. Скопируй URL, заканчивающийся на `/exec`.
10. В Memory Card открой **Настройки → Google Sheets**, вставь endpoint и секрет и проверь подключение.

> После изменения `Code.gs` нужно создавать **New version** существующего deployment. Один Save не обновляет опубликованный Web App.

Для текущего backend при прямом открытии `/exec` должно отображаться `version: 13`.

## Подключение друга

Другу нужны:

- ссылка на Memory Card;
- тот же `/exec` endpoint.

**`SYNC_SECRET` владельца другу передавать не нужно.** Сервер создаст отдельный профиль, библиотеку и Memory Card ID.

# Как устроена синхронизация

`Устройство ↔ Apps Script ↔ Google Sheets ↔ другое устройство`

Memory Card остаётся local-first: пустой или ошибочный ответ сервера не должен уничтожать локальную библиотеку. Перед sync создаётся локальный snapshot.

Apps Script Bridge использует HtmlService iframe + `google.script.run` + `postMessage`, чтобы GitHub Pages мог надёжно общаться с Apps Script без обычных CORS-проблем.

# Экспорт и безопасность

JSON export содержит игры, настройки, выбранные консоли, ротации и публичную информацию профиля.

В экспорт специально не попадают:

- `authToken`;
- `SYNC_SECRET`;
- приватные server credentials.

Не публикуй `SYNC_SECRET`. Персональная библиотека не хранится непосредственно в GitHub-коде приложения.
