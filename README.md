# Memory Card v0.16

**Memory Card** — local-first PWA для личной игровой библиотеки, истории прохождений, ротации консолей и небольшой закрытой социальной сети.

Приложение работает в браузере и устанавливается как PWA. Основные данные хранятся локально; Google Sheets + Apps Script используются для синхронизации между устройствами и профилями.

## Что умеет Memory Card

- библиотека со статусами **«Сейчас играю»** и **«Пройдено»**;
- отдельный **Backlog**, который не входит в библиотечную статистику до начала прохождения;
- оценки, заметки, даты, перепрохождения и история;
- отдельные портативная и desktop-ротации;
- режимы ротации **Классическая / Баланс / Случайная**;
- выбор собственных приставок;
- несколько видов библиотеки: **1 / 4 / 6 / 8 в ряд + Полка**;
- полноценные страницы игр и франшиз;
- пользовательские коллекции;
- **100 внутренних достижений**, из них 50 скрытых;
- профили друзей и сравнение игровых профилей;
- 12 визуальных акцентных тем;
- platform-aware hero/background и компактные badges на обложках;
- каталоги игр и автоматический box art;
- Русский / English;
- Google Sheets sync, snapshots и JSON export/import.

# Ротация

Memory Card поддерживает две независимые очереди: портативную и desktop.

Порядок систем настраивается вручную. Любую ротацию можно отключить. Режим **Баланс** использует историю библиотеки и выбирает платформу, на которой ты дольше всего не играл; **Случайная** выбирает следующую систему случайно; **Классическая** следует порядку очереди.

# Backlog

Backlog — отдельная очередь будущих прохождений. Запись Backlog хранится и синхронизируется, но не считается полноценной библиотечной игрой.

Допустимый переход:

`Backlog → Сейчас играю → Пройдено`

Переход `Backlog → Пройдено` намеренно отсутствует.

# Коллекции

Коллекции — пользовательские тематические списки поверх уже существующей библиотеки. Удаление коллекции не удаляет игры.

# Профили и друзья

После подключения Apps Script пользователь получает ID вида `MC-AB12-CD34`. Пользователь находится только по точному ID. Профиль открывается после подтверждения дружбы и работает только для чтения.

Backlog и личные notes друзьям не передаются.

# Оформление

В настройках доступны системная / светлая / тёмная тема, Русский / English, reduced motion и 12 акцентных visual themes.

# Google Sheets + Apps Script

1. Открой Google Sheet → **Расширения → Apps Script**.
2. Замени `Code.gs` файлом из этого репозитория.
3. Сохрани.
4. **Deploy → Manage deployments → Edit → New version → Deploy**.
5. Оставь прежний `/exec` URL.

Для текущего релиза прямой ответ `/exec` должен содержать `version: 16`.

> `SYNC_SECRET` владельца нельзя передавать друзьям. Другу нужен только общий `/exec` endpoint; сервер создаёт ему отдельный профиль.
