# Memory Card v0.17

**Memory Card** — local-first PWA для личной игровой библиотеки, ротации консолей, Backlog, коллекций, достижений и небольшой закрытой социальной сети.

Приложение работает в браузере и устанавливается как PWA. Основные данные хранятся локально; Google Sheets + Apps Script используются для синхронизации между устройствами и профилями.

## Что умеет Memory Card

- библиотека со статусами **«Сейчас играю»** и **«Пройдено»**;
- отдельный **Backlog**, который не входит в статистику до начала прохождения;
- оценки, заметки, даты и перепрохождения;
- handheld и desktop-ротации;
- режимы ротации **Классическая / Баланс / Случайная**;
- выбор собственных приставок;
- виды библиотеки **1 / 4 / 6 / 8 в ряд + Полка**;
- полноценные страницы игр и франшиз;
- пользовательские коллекции;
- **100 достижений**, из них 50 скрытых;
- профили друзей и сравнение профилей;
- **24 visual styles / accent themes**;
- platform-aware hero/background и badges на обложках;
- каталоги игр и автоматический box art;
- ручное обновление обложки одной игры;
- Русский / English;
- Google Sheets sync, snapshots и JSON export/import.

Полный spoiler-лист достижений: **[ACHIEVEMENTS.md](./ACHIEVEMENTS.md)**.

### Backlog + каталог

- Backlog теперь использует общий локальный каталог Memory Card.
- При вводе названия появляются подсказки.
- Выбор игры из подсказки автоматически подставляет корректное название и год; если каталог знает жанр/франшизу — они тоже заполняются.
- При сохранении сразу используется найденная catalog cover, затем обычный resolver как fallback.

### Главная и ротация

- Исправлено сохранение **текущей приставки** из настроек ротации.
- Главная теперь учитывает текущую платформу ротации.
- Если обе ротации выключены, hero случайно выбирает одну из всех текущих игр при открытии/обновлении страницы.
- Если ротация включена, случайная игра берётся только из текущей платформы соответствующей ротации.
- Классическая / Баланс / Случайная теперь выбираются крупными кнопками вместо select.

### Обложки

На detail-page игры появилась кнопка **«↻ Обновить обложку»**.

При ручном обновлении Memory Card сначала ищет строгое совпадение в Libretro Named_Boxarts, в том числе понимает варианты вроде `II` ↔ `2`, затем использует точный каталог и общий resolver. Это снижает шанс ложного совпадения вроде Assassin's Creed II → Assassin's Creed III.

### Коллекции

- Исправлено нестабильное добавление игр в коллекции.
- Изменение теперь записывается immutable-обновлением настроек и лучше переживает re-render / autosync.

### Визуал

- Исправлен плохой контраст тёмных плашек в light theme на странице игры и в настройках.
- Accent styles стали полноценными визуальными карточками с названиями.
- Всего теперь **24 стиля**; первые 8 видны сразу, остальные открываются через **«Показать все стили»**.
- Новые стили: **PS1 Smoke · PSP XMB · PS3 Wave · Switch Neon · GameCube Indigo · Wii Ice · Nintendo 64 · SNES Lavender · Mega Drive · Xbox 360 Blades · DSi White · 3DS Red**.
- Со страницы достижений убрана лишняя фраза про playtime.

# Ротация

Memory Card поддерживает две независимые очереди: портативную и desktop.

### Классическая
Следует заданному порядку устройств.

### Баланс
Следующей становится система, на которой дольше всего не было активности.

### Случайная
Следующая система выбирается случайно из очереди, кроме текущей.

Любую из двух ротаций можно полностью отключить. При выключенных ротациях Currently Playing на главной выбирается случайно среди всех активных прохождений.

# Backlog

Backlog — отдельная очередь будущих прохождений. Он синхронизируется, но не считается полноценной библиотечной игрой.

Допустимый путь:

`Backlog → Сейчас играю → Пройдено`

Переход `Backlog → Пройдено` намеренно отсутствует.

# Коллекции

Коллекции — пользовательские тематические списки поверх существующей библиотеки. Удаление коллекции не удаляет игры.

# Обложки

Memory Card использует общий cover registry, Libretro Named_Boxarts, специализированные источники PSP / Vita / PS3, GameTDB для Switch и fallback-источники для современных систем.

Если автоматический resolver выбрал неправильную картинку, открой страницу игры и нажми **«Обновить обложку»**.

# Профили и друзья

После подключения Apps Script пользователь получает ID вида `MC-AB12-CD34`. Пользователь находится только по точному ID. Профиль открывается после подтверждения дружбы и работает только для чтения.

Backlog и личные notes друзьям не передаются.

# Оформление

Доступны системная / светлая / тёмная тема, Русский / English, reduced motion и 24 визуальных accent styles.

# Google Sheets + Apps Script

Для текущей версии backend должен быть **version 16**.

1. Открой Google Sheet → **Расширения → Apps Script**.
2. Если backend ещё старее v16 — замени `Code.gs` файлом из репозитория.
3. **Deploy → Manage deployments → Edit → New version → Deploy**.
4. Оставь прежний `/exec` URL.

Для самого обновления **v0.17 повторный deploy Apps Script не нужен**.

> `SYNC_SECRET` владельца нельзя передавать друзьям. Другу нужен только общий `/exec` endpoint.
