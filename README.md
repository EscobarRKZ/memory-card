# Memory Card v0.13

**Memory Card** — local-first PWA для личной игровой библиотеки, истории прохождений, ротации консолей и небольшой закрытой социальной сети для друзей.

Приложение работает прямо в браузере и может устанавливаться как PWA на телефоне и компьютере. Основные данные хранятся локально, а Google Sheets + Apps Script используются для синхронизации между устройствами и профилями.

## Что умеет Memory Card

- вести библиотеку игр со статусами **«Играю»** и **«Пройдено»**;
- хранить оценки, заметки, даты и перепрохождения;
- показывать игровую статистику и таймлайн;
- вести отдельные ротации **портативных** и **стационарных** устройств;
- выбирать только те консоли, которыми ты реально пользуешься;
- показывать на главной только выбранные приставки, не перегружая экран;
- включать и выключать портативную и desktop-ротацию независимо;
- автоматически подбирать и восстанавливать обложки игр из нескольких источников;
- обновлять каталоги только для выбранных пользователем платформ;
- синхронизировать библиотеку между устройствами через Google Sheets;
- создавать профиль Memory Card с уникальным ID;
- добавлять друзей по точному ID и смотреть их игровые профили после подтверждения дружбы;
- переключать интерфейс между **Русским** и **English**;
- экспортировать и импортировать библиотеку без передачи приватных токенов.

# Ротация устройств

Memory Card позволяет вести две независимые очереди.

### Портативная ротация

Например:

`DSi → PS Vita → 3DS → PSP → GBA → ...`

### Стационарная ротация

Например:

`PS3 → Wii U → Nintendo Switch → ...`

Порядок полностью настраивается. Любую из двух ротаций можно отключить.

Когда игра на текущей системе закончена, можно завершить этап ротации: выбрать активную игру, поставить оценку, сохранить прохождение и автоматически перейти к следующей консоли.

# Профили и друзья

У каждого пользователя есть собственный профиль Memory Card.

После подключения к Apps Script Memory Card выдаёт ID вида:

`MC-AB12-CD34`

Чтобы добавить друга:

1. Открой раздел **«Друзья»**.
2. Введи точный Memory Card ID друга.
3. Отправь заявку.
4. Друг принимает её у себя.
5. После этого вы можете смотреть игровые профили друг друга.

Профиль друга работает только для чтения. Его библиотеку изменить нельзя.

Если дружба удалена, сервер немедленно закрывает профили друг от друга. Пользователь, которого удалили, видит уведомление об этом и может убрать его из списка.

# Google Sheets + Apps Script

Google Sheets используется как облачная база и точка синхронизации.

## Первичная настройка владельца

1. Создай Google Sheet для Memory Card.
2. Открой **Расширения → Apps Script**.
3. Замени содержимое `Code.gs` файлом **`Code.gs` из корня этого репозитория**.
4. В Apps Script открой **Project Settings → Script Properties**.
5. Создай свойство:
   - Property: `SYNC_SECRET`
   - Value: длинная случайная строка.
6. Выбери **Deploy → New deployment → Web app**.
7. Настройки Web App:
   - **Execute as:** Me
   - **Who has access:** Anyone
8. Скопируй URL, заканчивающийся на `/exec`.
9. В Memory Card открой **Настройки → Google Sheets** и вставь endpoint и `SYNC_SECRET`.
10. Сохрани настройки и проверь подключение.

> После любого изменения `Code.gs` недостаточно просто нажать Save. Нужно открыть **Deploy → Manage deployments → Edit → New version → Deploy**. URL `/exec` при этом можно оставить прежним.

Для текущей версии при прямом открытии `/exec` сервер должен сообщать `version: 13`.

## Подключение друга

Другу нужны только:

- ссылка на Memory Card;
- тот же Apps Script `/exec` endpoint.

**Передавать другу `SYNC_SECRET` владельца не нужно.**

Друг указывает endpoint и своё имя. Сервер создаёт ему отдельный профиль, отдельную библиотеку и отдельный Memory Card ID.

# Как устроена синхронизация

Memory Card придерживается local-first подхода:

`Устройство ↔ Apps Script ↔ Google Sheets ↔ другое устройство`

Локальная библиотека не уничтожается из-за пустого или ошибочного ответа сервера. При синхронизации записи объединяются по ID и времени обновления.

Перед sync создаётся локальная резервная копия.

Apps Script Bridge используется для обхода ограничений CORS GitHub Pages / Google Apps Script: скрытый HtmlService iframe вызывает серверные функции через `google.script.run` и возвращает результат приложению через `postMessage`.

# Каталоги и обложки игр

Каталоги загружаются только для систем, выбранных в **«Мои приставки»**. Это уменьшает лишние запросы и не тратит время на платформы, которыми пользователь не пользуется.

Для каталогов используются platform-specific SQL-базы и GameTDB. На текущем этапе отдельного источника каталога нет для PS5 и Xbox Series.

Для обложек Memory Card использует несколько источников и fallback-механизмов, потому что универсальной качественной базы box art для всех поколений нет.

В зависимости от платформы используются:

- Libretro Thumbnails / `Named_Boxarts`;
- title-ID базы;
- GameTDB;
- Wikipedia как строгий fallback;
- VitaDB / HexFlow для PS Vita;
- дополнительные platform-specific источники.

Если достоверную обложку найти не удаётся, приложение предпочитает fallback-карточку неправильному изображению.
