# Memory Card v0.5 — личный игровой журнал

Local-first PWA для истории прохождений, двух ротаций устройств и синхронизации между Mac и телефоном через Google Sheets.

## Что нового в v0.5

- **Следующая приставка в ротации теперь кликабельна.** Нажми на выделенную следующую консоль в карточке ротации.
- Откроется окно завершения текущего этапа ротации:
  - выбираешь игру со статусом **«Играю»** на текущей приставке;
  - ставишь оценку 1–10;
  - при желании дописываешь комментарий и номер перепрохождения;
  - нажимаешь «Завершить и перейти».
- Игра автоматически получает статус **«Пройдено»**, а текущая приставка ротации переключается на следующую.
- Кнопки **«Сейчас играю» убраны из карточек ротации**. Для активных игр остаётся отдельный раздел меню «Сейчас играю» и кнопка на главной.
- Исправлена логика обложек:
  - «Обновить каталог» теперь обогащает уже добавленные записи;
  - отдельная кнопка **«Обновить обложки»** ищет постеры только для твоей библиотеки, а не пытается скачивать тысячи картинок каталога;
  - поиск обложки делает несколько запросов в English/Russian Wikipedia и кэширует найденный URL;
  - при добавлении новой игры без обложки приложение само пытается найти её в фоне.
- Улучшена мобильная вёрстка:
  - модальные окна превращаются в удобные bottom sheets;
  - формы имеют крупные touch-targets;
  - ротация листается горизонтально;
  - адаптированы карточки, обложки, нижняя навигация и safe-area iPhone;
  - интерфейс нормально работает как установленная PWA.
- Добавлена **автосинхронизация** с Google Sheets:
  - при открытии приложения;
  - при возвращении в приложение;
  - после изменения игр и ротации.

## Логика ротации

### Портативки
По умолчанию:

`DSi → PS Vita → 3DS → PSP → GBA → ...`

### Desktop
По умолчанию:

`PS3 → Wii U → Nintendo Switch → ...`

Порядок и текущая консоль меняются в настройках.

Если, например, сейчас на PSP запущена LocoRoco, а следующая в ротации GBA:

1. На главной в «Портативной ротации» GBA подсвечена как следующая.
2. Нажимаешь GBA.
3. Memory Card предлагает активные игры на PSP.
4. Выбираешь LocoRoco, ставишь оценку и сохраняешь.
5. LocoRoco уходит в архив пройденных.
6. Текущей портативкой становится GBA.

## Почему раньше могли не появляться обложки

Каталог игр и каталог изображений — разные задачи. Дополнительная ретро-база содержит много названий/лет/жанров, но практически не содержит artwork. Wikidata также далеко не у каждой игры имеет `P18`.

В v0.5 обложка для **твоей конкретной записи** дополнительно ищется через Wikipedia. Поэтому после обновления версии:

1. Открой **Настройки → Каталог игр и обложки**.
2. Нажми **«Обновить каталог»**.
3. После него нажми **«Обновить обложки»**.
4. Оставь приложение открытым на время поиска. Для этого нужен интернет.

Если открытой картинки для конкретной игры всё равно нет, останется цветная fallback-обложка.

# Как сделать приложение на телефоне

Memory Card — PWA. APK/IPA не обязателен: один и тот же код работает на Mac, iPhone и Android.

Для телефона приложение должно открываться по **HTTPS-адресу**, а не через `localhost` на Mac. Самый простой постоянный вариант — GitHub Pages.

## Вариант: GitHub Pages

1. Создай пустой репозиторий на GitHub, например `memory-card`.
2. Положи **содержимое папки `memory-card-v0.5`** в корень репозитория (`index.html`, `app.js`, `styles.css`, `manifest.webmanifest`, картинки и т. д.).
3. GitHub → репозиторий → **Settings → Pages**.
4. Source: **Deploy from a branch**.
5. Branch: `main`, folder: `/ (root)`.
6. Через минуту GitHub выдаст адрес вида:
   `https://USERNAME.github.io/memory-card/`
7. Открывай один и тот же URL на Mac и телефоне.

Личные игры в GitHub **не публикуются**: библиотека хранится в браузере/IndexedDB и в твоей Google Таблице. В репозитории лежит только оболочка приложения.

### iPhone / iPad

1. Открой URL в Safari.
2. Нажми **Поделиться**.
3. **На экран «Домой» / Add to Home Screen**.
4. Memory Card появится как отдельное приложение с логотипом.

### Android

1. Открой URL в Chrome.
2. Меню `⋮` → **Установить приложение / Add to Home screen**.
3. Запускай с иконки как обычное приложение.

### Mac

Можно продолжать запускать `start.command`, но для идеальной синхронизации удобнее использовать тот же GitHub Pages URL. В Chrome/Safari его также можно установить как web app.

# Настройка Google Sheets — пошагово

Google Таблица будет центральным облаком между Mac и телефоном.

## 1. Создай таблицу

Открой Google Sheets → **Пустая таблица**. Например назови её `Memory Card`.

Ничего вручную в листах создавать не нужно.

## 2. Открой Apps Script

В таблице:

**Расширения / Extensions → Apps Script**.

Удаляешь код, который там есть, и вставляешь **весь файл**:

`google-apps-script/Code.gs`

из этого архива.

Сохрани проект.

## 3. Создай секрет

В Apps Script открой:

**Project Settings / Настройки проекта → Script Properties / Свойства скрипта**.

Добавь свойство:

- Property: `SYNC_SECRET`
- Value: придумай длинную строку, например случайные 30–50 символов.

Это пароль между приложением и твоей таблицей.

## 4. Опубликуй Web App

Apps Script:

**Deploy → New deployment → Web app**.

Настройки:

- Execute as: **Me**
- Who has access: **Anyone**

Нажми Deploy и пройди авторизацию Google.

Скопируй URL, который заканчивается на:

`/exec`

Это твой **Apps Script endpoint**.

> Если потом меняешь `Code.gs`, открой **Deploy → Manage deployments → Edit → New version → Deploy**. Старый endpoint при этом можно сохранить.

## 5. Подключи Mac

Memory Card → **Настройки → Google Sheets**:

- Apps Script endpoint → вставь `/exec` URL;
- Секрет → вставь значение `SYNC_SECRET`;
- включи **Автосинхронизацию**;
- нажми **Сохранить настройки**;
- затем **Синхронизировать сейчас**.

После первого sync в Google Таблице автоматически появятся:

- `Games`
- листы платформ (`PSP`, `VITA`, `3DS`, ...)
- `Stats`
- `Settings`

## 6. Подключи телефон

На телефоне открой/установи тот же Memory Card PWA.

В его настройках **один раз** введи тот же:

- Apps Script endpoint;
- `SYNC_SECRET`;
- включи автосинхронизацию.

Нажми **Синхронизировать сейчас**.

Телефон скачает библиотеку из таблицы.

Дальше схема такая:

`Mac ↔ Google Sheets ↔ Phone`

Приложение сравнивает записи по уникальному ID и `updatedAt`; более новая версия записи побеждает.

Endpoint и секрет **не синхронизируются через Google Sheets** специально: они остаются только в локальном хранилище каждого устройства.

## Локальный запуск на Mac

Дважды кликни `start.command` или:

```bash
cd memory-card-v0.5
python3 -m http.server 8080
```

Затем открой:

`http://localhost:8080`

## Google Sheets schema

`id | platform | title | releaseYear | genre | franchise | coverUrl | status | rating | replay | notes | addedAt | updatedAt | deletedAt`

## Безопасность и резервная копия

- Google Sheets выступает облачной копией и точкой синхронизации.
- Для дополнительного бэкапа в приложении остаётся **Экспорт JSON**.
- Не публикуй `SYNC_SECRET` в репозитории или скриншотах.
- Код приложения можно держать публичным: персональные данные в него не вшиваются.

## v0.7 — исправление обложек и индикатор фоновых задач

- Обложки больше не берутся из Wikidata `P18`: это поле часто содержит любую свободную иллюстрацию к игре (фото разработчика, мероприятие, скриншот), а не box art.
- Новый поиск идёт через Wikipedia и затем проверяет Wikidata-сущность найденной страницы: это должна быть видеоигра, а при наличии данных — версия для выбранной платформы и близкий год релиза.
- Старые непроверенные обложки из v0.4/v0.5 автоматически сбрасываются один раз. После обновления открой **Настройки → Обновить обложки**.
- Ручная синхронизация, обновление каталога и поиск обложек показывают прогресс в правом нижнем углу. На телефоне индикатор расположен над нижней навигацией.


## Важно при обновлении с v0.6 на v0.7

В v0.7 исправлена синхронизация с Google Apps Script при запуске приложения с GitHub Pages. Обычный `fetch()` мог падать с `Failed to fetch` из-за CORS/редиректа Google, даже когда `/exec` был опубликован правильно.

После замены файлов приложения **обязательно обновите Apps Script**:

1. В Google Таблице откройте **Расширения → Apps Script**.
2. Полностью замените `Code.gs` файлом из папки `google-apps-script/Code.gs` версии v0.7.
3. Нажмите **Сохранить проект**.
4. Справа сверху выберите **Развернуть → Управление развертываниями**.
5. Нажмите значок карандаша у текущего веб-приложения.
6. В поле **Версия** выберите **Новая версия**.
7. Нажмите **Развернуть**.
8. URL `/exec` и `SYNC_SECRET` менять не нужно.

Новая схема синхронизации: приложение отправляет изменения POST-запросом без попытки прочитать CORS-заблокированный ответ, затем отдельным JSONP-запросом получает объединённую библиотеку обратно. Это рассчитано именно на GitHub Pages/PWA и одинаково работает на Mac и телефоне.

## v0.9 — исправление синхронизации и обложек

- Исправлен transport Apps Script: Google HtmlService может создавать внутренний sandbox iframe, поэтому `message` приходит не от внешнего iframe напрямую. Проверка `event.source === iframe.contentWindow` удалена; ответ связывается с запросом по случайному `requestId`.
- Поиск обложки больше не использует `pageimages`. Он сначала находит и проверяет статью игры через Wikidata, затем берёт только подходящее изображение из `table.infobox` и отбрасывает logo/screenshot/developer/person/photo. Если достоверной box-art нет, показывается цветная fallback-карточка вместо неправильного изображения.
- При первом запуске v0.9 все автоматически найденные старыми версиями обложки очищаются и могут быть перестроены через **Настройки → Обновить обложки**. Ручные обложки не удаляются.
