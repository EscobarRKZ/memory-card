Удаление аккаунта

Здесь можно отправить запрос на удаление аккаунта Memory Card, даже если приложение больше не установлено на телефоне.

Что будет удалено после обработки заявки

Учётная запись и связанные облачные данные: профиль, игровая библиотека, отзывы и оценки, настройки, коллекции и связи с друзьями. Простая отправка запроса ещё не удаляет данные.

Локальные данные и резервные копии на других устройствах могут оставаться в хранилище браузера. При необходимости их можно удалить через настройки браузера или данные приложения. Перед запросом рекомендуется экспортировать свои игры в JSON.

Отправить запрос

Для защиты аккаунта войди с email и паролем Memory Card. После входа можно проверить, есть ли уже заявка. Если пароль забыт, восстанови доступ на основной странице Memory Card.

Удалить аккаунт без ожидания обработки

После заявки можно окончательно удалить аккаунт самостоятельно. Все связанные облачные игры, заметки, оценки, коллекции и связи с друзьями будут удалены без возможности восстановления. Перед этим экспортируй библиотеку в Memory Card.

Что происходит дальше

После отправки заявки её можно завершить здесь через повторное подтверждение паролем. Если не завершать самостоятельно, заявка останется в очереди на обработку. Пока аккаунт не удалён, он продолжает работать.

При подтверждённом удалении связанные облачные данные удаляются. Копии, сохранённые на других устройствах или экспортированные вручную, нужно удалить отдельно. Пароль используется только для повторной проверки личности, не сохраняется в браузере и не записывается в журнал приложения.
