Удаление аккаунта

Здесь можно отправить запрос на удаление аккаунта Memory Card, даже если приложение больше не установлено на телефоне.

Что будет удалено после обработки заявки

Учётная запись и связанные облачные данные: профиль, игровая библиотека, отзывы и оценки, настройки, коллекции и связи с друзьями. Простая отправка запроса ещё не удаляет данные.

Локальные данные и резервные копии на других устройствах могут оставаться в хранилище браузера. При необходимости их можно удалить через настройки браузера или данные приложения. Перед запросом рекомендуется экспортировать свои игры в JSON.

Отправить запрос

Для защиты аккаунта войди с email и паролем Memory Card. После входа можно проверить, есть ли уже заявка. Если пароль забыт, восстанови доступ на основной странице Memory Card.

Проверяю доступность сервиса…

Что происходит дальше

Заявка получает статус «Ожидает обработки». Это не автоматическое удаление. Удаление данных будет выполнено отдельно после проверки запроса. Пока статус не изменился, аккаунт продолжает работать.

Не отправляй пароль или секретные ключи через сторонние формы. Этот сайт использует вход через Supabase Auth.
